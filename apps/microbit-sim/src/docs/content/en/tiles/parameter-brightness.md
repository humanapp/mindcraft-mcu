# Brightness

How brightly an LED lights.

---

Gives `tile:tile.actuator->microbit-v2.display-set-pixel` its brightness, a
number from 0 (off) to 255 (full). When left off, the pixel is set to full
brightness; use 0 to turn a pixel off.
